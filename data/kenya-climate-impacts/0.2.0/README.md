# Kenya climate impacts: credited review copies

Five data files with source-specific metadata and licence notices. This is a review hosting branch, not CDH catalogue acceptance. Files contain NOAA/HadISST ocean indices, HarvestStat county crop observations, WFP/NASA county NDVI and the World Bank exchange-rate extract. Read each sidecar before reuse. No restricted KNBS, NDMA, KAMIS, mixed trade, or valuation files are included.
