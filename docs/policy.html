Privacy Policy

Last updated: March 2026

This website uses GoatCounter, a privacy-friendly analytics tool, to understand general usage without tracking individuals.

Data Collection

We collect anonymous, aggregated statistics about website usage. This includes:

  • Pages visited
  • Browser type and version (e.g., Firefox, Chrome)
  • Operating system (e.g., Windows, macOS)
  • Country-level location (derived from IP address)
  • Language settings
  • Screen size

All data is stored in aggregate form only (e.g., total counts per page per day or hour). There is no way to link this data to individual users.

No Personal Tracking

  • No IP addresses are stored
  • No full User-Agent strings are stored
  • No unique identifiers or tracking IDs are used
  • No cookies, localStorage, or browser storage are used for tracking

We cannot identify you personally from the collected data.

Session Handling

To distinguish repeated visits within a short period:

  • A temporary, anonymous identifier may be created in memory
  • This exists for up to 8 hours only
  • It is not stored permanently and cannot be linked to individuals

Pageview Details

In some cases, limited per-visit data may be recorded (e.g., time, page, browser, country), but:

  • This remains anonymous
  • No personally identifiable information is collected
  • Data cannot be linked across sessions

Cookies

This website does not use cookies for tracking or analytics.

Data Sharing

  • No data is shared with third parties
  • No data is sold or used for advertising

Data Storage

Analytics data is processed and stored on servers operated by GoatCounter (hosted in the EU, e.g., Finland and Germany).

Your Rights

Under GDPR, you have the right to:

  • Request information about data processing
  • Request deletion of any personal data (if applicable)

However, as no personal data is stored, such requests are generally not applicable.
